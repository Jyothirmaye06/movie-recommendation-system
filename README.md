# 🎬 Movie Recommendation System

This project builds a **content-based movie recommendation system** using **NLP and cosine similarity**.

The system recommends movies similar to the selected movie based on features like **genres, keywords, cast, and overview**.

---

## 📂 Dataset

The dataset is too large to upload to GitHub.

Download it from Kaggle:

https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

Download these files:

* `tmdb_5000_movies.csv`
* `tmdb_5000_credits.csv`

Place them in the project folder before running the code.
---
## ⚙️ Installation
Install required libraries:
```
pip install -r requirements.txt

## ▶️ Run the Web App
```
streamlit run app.py
```
Then open:
```
http://localhost:8501
``
